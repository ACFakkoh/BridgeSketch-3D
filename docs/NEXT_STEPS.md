# Recommended next steps for BridgeSketch 3D

BridgeSketch 3D 0.4.1 now has curated examples, moving traffic, bundled vehicles and an offline/GitHub Pages release. The next improvements should help users check and present a concept accurately.

1. **Dimensioned live cross-section.** Move a station marker and show the actual lane widths, shoulders, sidewalks, median, barriers, girders and slab depth. Export the section as SVG.
2. **Ground and approach control.** Let users specify terrain levels and approach tie-ins, then show cut/fill and retaining-wall extents. The current landscape is an attractive concept scene, not a site model.
3. **Pier and wall editing per support.** Keep the global defaults simple, but allow individual piers and abutments to change type and dimension. Revisit wingwall geometry with user-provided dimensions and reference views.
4. **Concept comparison.** Save named alternatives A/B and show them with the same camera and a short parameter difference table.
5. **Concept sheet export.** Combine plan, elevation, section, perspective and key dimensions on a clean printable sheet.

Start with the cross-section: it makes the new lane controls and variable-depth structure legible, and offers a practical visual check before sharing a concept.
